# منابع تصاویر قابلیت‌ها

تصاویر این پوشه عکس آرشیوی نیستند. هر فایل یک تصویر ثابت سه‌بعدی‌نماست که برای هماهنگی با پس‌زمینهٔ تیره و رابط شیشه‌ای سایت ساخته شده است.

- ابزار تولید: `scripts/render-capability-art.py` (رندر CSS سه‌بعدی در Chrome headless، خروجی WebP با اندازهٔ ۸۰۰×۵۰۰)
- شمایل‌ها: [Lucide](https://lucide.dev) با پروانهٔ ISC
- سبک: شیشهٔ براق، احجام نورانی، شبکهٔ کم‌رنگ و پالت تیرهٔ سایت

برای بازتولید:

```bash
python3 scripts/render-capability-art.py
```
