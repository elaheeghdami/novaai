# تصاویر نمونه کارها

فایل‌های تصویر پروژه‌های اصلی را با همین نام‌ها اینجا قرار دهید (نسبت پیشنهادی ۱۶:۱۰، مثلاً ۱۶۰۰×۱۰۰۰):

- dentotech.jpg
- smart-scanner.jpg
- autonomous-car.jpg
- company.jpg

تصاویر پروژه‌های تخصصی بینایی ماشین در پوشهٔ `capabilities/` به‌صورت وب‌پی و با سبک سه‌بعدی یکدست تولید شده‌اند.
توضیحات پروژه‌های اصلی در `src/data/projects.ts` و پروژه‌های تخصصی در `src/data/capabilities.ts` قابل ویرایش است.
